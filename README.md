# 🏏 IPL Dataset Analysis using Python

## 📖 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the **Indian Premier League (IPL) Dataset** using Python.

The primary objective of this project is to uncover meaningful insights from IPL matches through **data cleaning, data visualization, and statistical analysis**.

This project answers several cricket-related questions, including:

- Which team has won the most matches?
- Who has scored the most runs?
- Who has taken the most wickets?
- Which stadium has hosted the most IPL matches?
- How does the toss decision affect match results?
- Which players hit the most boundaries?
- Powerplay and Death Overs performance analysis
- Batting and Bowling statistics
- Team performance across different seasons
- Match-winning trends and patterns

# 📊 Dataset

This project uses two IPL datasets.

## Matches Dataset

Contains match-level information such as:

- Match ID
- Season
- Team 1
- Team 2
- Toss Winner
- Toss Decision
- Match Winner
- Venue
- Umpires
- Result

## Deliveries Dataset

Contains ball-by-ball information such as:

- Match ID
- Innings
- Batting Team
- Bowling Team
- Batter
- Bowler
- Runs Scored
- Extra Runs
- Wickets
- Overs
- Ball-by-ball Details
